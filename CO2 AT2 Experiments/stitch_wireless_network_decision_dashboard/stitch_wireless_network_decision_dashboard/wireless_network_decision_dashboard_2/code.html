Decision Rationale & Trade-offs

The BL4 rule-based decision engine weighs spatial availability against energy overhead and routing complexity. When infrastructure is fully available and node density is high, cellular backhaul minimizes latency through carrier-grade handovers. Conversely, isolated environments eliminate cellular dependence, shifting preference toward decentralized MANET topologies despite their higher routing overhead.

Triangle routing penalty minimized via route optimization extensions.
Energy thresholds penalize MANET protocols in battery-constrained IoT grids.
security

Security & Reliability Considerations

Mission-critical academic deployments require strict authentication between mobile nodes and home agents to prevent IP spoofing and interception. MANET architectures introduce vulnerability to black-hole and sinkhole attacks due to untrusted intermediate forwarding nodes, necessitating secure routing protocols (e.g., SA-AODV).

IPSec encapsulation recommended for all Mobile IP signaling channels.
Redundant home agents ensure failover capability during disaster response.
