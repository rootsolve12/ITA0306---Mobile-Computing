Step 1: Agent Discovery

The Mobile Node (MN) listens for Agent Advertisements broadcasted periodically by routers. If no advertisements are heard, the MN may actively solicit an agent by sending an Agent Solicitation message. This allows the mobile node to determine whether it is currently attached to its home network or visiting a foreign network.

1. Handoff Delay

Registration latencies and periodic agent advertisements can introduce delays during roaming, temporarily interrupting active real-time communication sessions.

2. Packet Loss Risk

Packets routed toward the home network before registration completes at the Home Agent may be dropped or delayed until the tunnel is fully established.

3. Route Optimization
